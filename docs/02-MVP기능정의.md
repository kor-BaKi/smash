# 02. MVP 기능 정의 & 로드맵

> 최종 갱신: 2026-11. Phase 1~3의 대부분이 구현 완료되어 상태 표시를 추가했다.

## MVP 판단 기준
1. 서비스 핵심 가치(고유 운영 규칙 시스템화)와 직접 연결
2. 없으면 서비스가 성립하지 않음
3. 1인 개발로 완성 가능한 범위

## Phase 1 (MVP) — 구현 완료
| # | 기능 | 상태 | 비고 |
|---|---|---|---|
| ① | 회원가입/로그인 (가입코드 + 학번 대조) | ✅ | 사전등록 PENDING → 가입 ACTIVE, 로그인 실패 잠금 |
| ② | 임원/부원 권한 구분 (ROLE_ADMIN/MEMBER) | ✅ | 임원 지정/해제, 마지막 임원 보호 |
| ③ | 조 편성 + 조장·부조장 지정 + 정규활동 일정 설정 | ✅ | |
| ④ | 가능 요일 수집 + 자동 조 배정 (preview/confirm) | ✅ | |
| ⑤ | 매일 활동 투표 자동 생성 + 참여 유형 분기 | ✅ | 스케줄러 + 기동 시 보정 |
| ⑥ | 이월 처리 (보장 자격 이동) | ✅ | 당월 내 이월 |

## Phase 2 — 서비스 확장 (구현 완료)
| 기능 | 상태 |
|---|---|
| 공지 | 별도 공지 대신 일반 투표(Poll) + 동아리 일정(Calendar) + 푸시로 대체 |
| 회비 납부 상태 관리 | ✅ (납부/취소/학기 초기화) |
| 자유활동 기간 설정 | ✅ (기간 겹침 방지) |
| 푸시 알림 | ✅ FCM, 알림 종류별 on/off, 탭 시 이동용 data payload |

| 기능 | 상태 |

| 이동 동행 관리 (호차 편성, 이동 방식 TOGETHER/ALONE) | ✅ |

| 동아리 일정 캘린더 | ✅ |
| 활동 캘린더 (실제 활동 + 미래 예정일 투영 + 자유활동 기간) | ✅ |
| 계정 관련 (비밀번호 변경, 회원 탈퇴, 가입 거절/복구) | ✅ |

| 지난학기 조편성 복제 | ❌ (학기 초기화 후 재배정 방식) |

## 제외 (전 Phase 공통)
체육관비 금액 계산 / PG 결제 / 구글폼 API / 카톡 자동초대 / 복식 매칭·랭킹

## MVP가 증명하는 것
- 가능 요일 기반 균형 자동 배정 (제약 만족 알고리즘)
- 매일 투표 생성·집계 자동화 (스케줄러)
- 조장 머릿속 이월 판단의 데이터화 (상태 전이 로직)
- 월 4회 충족 계산 자동화

임원: 홈 / 조 편성·조장·부조장 / 정규일정·가입코드 / 자동배정(미리보기·수정·확정) ★ / 미배정자 /
      부원 목록·상세(메모) / 사전등록(단건·대량) / 대기·거절 관리 / 활동 현황·참여자 /
